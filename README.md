Парсер Ozon с WAF защитой. Реализован обход защиты, детекции TLS отпечатков и AntiBot проверок. В .env файл вставляется интересующая ссылка, при запуске скрипта, парсер собирает все объявления по этой ссылке и аккуартно упаковывает их в .json файл по методу слияния (не заменяя, а дополняя файл).

Данный проект показывает мое умение пробивать тир 1 защиту. В коммерческой разработке, такие сервисы как Ozon являются целями максимальной категории сложности.
