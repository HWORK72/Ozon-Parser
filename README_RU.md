Высокопроизводительный асинхронный скрейпер маркетплейса Ozon с обходом корпоративных систем фильтрации трафика (WAF), эмуляцией браузерных отпечатков TLS и инкрементальным объединением данных.

### Архитектурные особенности:
* **Обход WAF и TLS-фингерпринтинг:** Имитация криптографических отпечатков браузеров (JA3/JA4) и структуры HTTP/2 фреймов для предотвращения блокировок со стороны AntiBot-фильтров.
* **Инкрементальное слияние (State Merging):** Автоматическая дедупликация и бесшовное объединение новых позиций каталога с существующим JSON-датасетом без перезаписи исторических данных.
* **Конфигурация через окружение:** Управление поисковыми сессиями, таргетированными URL категорий и параметрами запросов через изолированный файл `.env`.
* **Устойчивость к изменениям DOM:** Модульная схема извлечения метаданных товаров (цены, скидки, артикулы, рейтинги) с валидацией целостности полей.

### Стек технологий:
* Python 3.12
* curl_cffi (Низкоуровневая эмуляция TLS/JA4 отпечатков)
* BeautifulSoup4 (Высокоскоростной парсинг DOM-дерева)
* python-dotenv (Управление конфигурацией)
